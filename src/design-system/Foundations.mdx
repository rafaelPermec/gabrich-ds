## Tokens semânticos

Componentes devem consumir **apenas** tokens semânticos; eles mudam com o tema e com a vertical.

| Token | Light | Dark |
|---|---|---|
| `--bg-base` | `--color-paper` | `--color-ink` |
| `--bg-surface` | `#ffffff` | `--color-cocoa-deep` |
| `--bg-subtle` | `--color-neutral` | `--color-border-dark` |
| `--text-primary` | `--color-ink` | `--color-paper` |
| `--text-secondary` | `--color-cocoa-matte` | `--color-sand` |
| `--text-muted` | `--color-sand` | `--color-border-dark` |
| `--border-base` | `--color-neutral` | `--color-border-dark` |
| `--border-strong` | `--color-ink` | `--color-paper` |
| `--accent-primary` | `--color-ochre` | `--color-ochre` |
| `--accent-warm` | `--color-caramel` | `--color-caramel` |

### Alphas e overlays

| Token | Uso |
|---|---|
| `--overlay-heavy` | Backdrop de Modal, overlay do PortfolioGrid |
| `--overlay-mid` | Overlay do Drawer |
| `--gradient-ink-overlay` | Gradiente sobre fotos |
| `--bg-subtle-alpha` | Zebra de tabela, fundos de demo |
| `--bg-hover` | Hover de linhas |
| `--accent-subtle` · `--accent-mid` | Realces em ocre |
| `--skeleton-shimmer` | Brilho do Skeleton |

## Forma

| Token | Valor | Gesto |
|---|---|---|
| `--radius-none` | `0` | **Enquadra** — card, foto, etiqueta, tabela, botão traçado |
| `--radius-full` | `9999px` | **Marca** — disco de ação, numeração, avatar, marcador |

Qualquer raio intermediário (4, 6, 8, 12, 16px…) está **fora do sistema**.
